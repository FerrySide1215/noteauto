# 叶結び 石川編 DAY1 ナレーション原稿
# テーマ：いったん止まって、整える。
# ※各ブロックの [id] は timeline / config の scene id と対応。
# ※本文は仕様書からの確定稿。録音時はここを読み上げる。

[cold_open]
金運で知られる神社から始まった、今回の石川の旅。
最初のおみくじに書かれていたのは、
「商売、思いがけぬ損あり」
でした。
そして次に訪れた神社でも、
また別のおみくじでも、
なぜか似たような言葉が続きます。
これは偶然なのか。
今回は、おみくじを一枚ずつではなく、
旅の流れとして読んでみます。

[kinkengu]
最初に訪れたのは金劔宮。
金運のことも少し意識しながら来た場所でした。
ところが引いたおみくじは、末吉。
しかも商売の欄には、
「思いがけぬ損あり」
とあります。
さらに全体では、
大きな問題というより、
小さなところを疎かにしないこと。
思いがけない出来事に慌てないこと。
そんな注意が書かれていました。
正直、この時はまだ、
「まあ、おみくじだからこういう時もある」
くらいに思っていました。

[shirayama_kaiun]
次は白山比咩神社。
ここでは、開運みくじを引きました。
第二十番、小吉。
風地観。
内容を読んでいて、
一つ気になったことがあります。
外へ向かって何かを増やすより、
まず自分自身をよく見る。
精神的な努力を重ねる。
自分を磨く。
そんな意味合いがとても強いおみくじでした。

[shirayama_kaiun_money]
そして、お金の部分。
意外な出費。
他人の金儲けが目につきやすい。
ここで私は少し引っかかりました。
金劔宮でも、
「思いがけぬ損」
と言われたばかりだったからです。

[shirayama_futsu]
さらに、普通のおみくじも引いてみました。
こちらも小吉。
そして、また似た言葉が出ます。
他人の出世を羨まない。
自分の仕事を嫌にならない。
欲を抑える。
そして特に、
「口」
つまり言葉に注意すること。
勢いで言う。
感情で言う。
大きなことを言い切る。
そういったことへの注意が
かなり強く書かれていました。

[shirayama_futsu_beat]
……あれ？
また同じ方向じゃない？

[day1_midsummary]
吉か凶かは違っても、
内容を並べてみると、
不思議なくらい同じ方向を向いていました。
新しいものを追うより、
今あるものを整える。
外を見るより、
自分の足元を見る。
そんな感じです。

[hattori]
1日目、最後のおみくじ。
ここで出てきたのは、
岩の上に根を張る松。
風や雪に耐えながら、
それでも根を張り続ける。
そして、やがて栄える。
という言葉でした。

[hattori_read]
ここまでのおみくじを重ねると、
今すぐ大きく動け、
ではない。
むしろ、
焦らず、
余計なものを増やさず、
今いる場所で根を張れ。
そう言われているように、
私には見えました。

[day1_ending]
石川の旅、1日目。
私が受け取ったメッセージは、
「いったん止まって、整える」
でした。
焦らない。
人と比べない。
言葉、人、お金、
そして小さな部分を丁寧に扱う。
ただ、この旅はここで終わりません。
翌日。
那谷寺を訪れたところから、
おみくじの流れが、
少し変わり始めます。
