# リール05｜わらしべ長者 ― 一本の藁から始まる幸運

- **カテゴリ**：日本の昔話
- **おすすめ投稿日**：9/26(土)【一粒万倍日 × 大安・最強日／月の締め】
- **想定尺**：45〜50秒
- **元ネタ**：『今昔物語集』『宇治拾遺物語』などに伝わる昔話**「わらしべ長者」**。観音様のお告げに従い、最初に手にした一本の藁を大切にした貧しい男が、藁→みかん→反物→馬→屋敷…と次々に交換して長者になる物語。「たった一つの小さなもの」を活かして富を育てる、一粒万倍の精神そのもの。
- **狙い**：月の締めくくり。「一粒を、めぐらせて育てる」というポジティブな読後感で。

## 📝 キャプション（投稿文）

```
たった一本の“藁”から、長者になった話🌾

貧しい男が観音様に祈ると、
「最初に手にしたものを大切にしなさい」とお告げが。
男がつかんだのは、道端の一本の藁でした。

その藁にアブを結ぶと、子どもがほしがってミカンと交換。
　ミカン → 反物 → 馬 → 立派な屋敷へ…！

何も持たなかった男は、
たった一本の藁を“めぐらせて育て”、長者になりました。
（昔話「わらしべ長者」）

大事なのは、大きさじゃなく“活かし方”。
あなたの手の中の小さな一つは、なんですか？

今日 9/26 は、今月最後の【一粒万倍日 × 大安】🌟
その一粒を、どうか大切に🌱

#わらしべ長者 #一粒万倍日 #大安 #日本の昔話 #開運 #9月 #金運アップ #暦のある暮らし #小さな一歩
```

## 🎵 演出メモ

- 交換の「昇格」テンポがこの回の気持ちよさ。藁→みかん→反物→馬→屋敷を**リズミカルに**。
- 月の最終回なので、締めは「今月ありがとう」的な余韻を音で演出。
- 「大きさより活かし方」を一枚画としてサムネ候補に。
